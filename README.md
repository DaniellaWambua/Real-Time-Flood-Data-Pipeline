# Real-Time Flood Data Pipeline for Early Warning Systems Using LSTM

Final-year capstone project (Strathmore University, BSc Informatics and Computer Science).
Supervisor: Dr Dickson Owuor.

The system monitors four Nairobi river catchments (Nairobi River, Mathare, Ngong, Motoine)
using hydrometeorological data and an LSTM Autoencoder for flood anomaly detection.

## Project layout

```
data/
  raw/         Original merged datasets (features + labels), one row per catchment per day
  processed/   Windowed and scaled arrays generated by src/preprocessing.py (not committed)
src/
  config.py         Paths, catchment list, hyperparameters, colour palette
  data_loading.py    Loads and validates the raw CSVs
  preprocessing.py   Builds sliding windows, scales features, splits train/val/test
  model.py           LSTM Autoencoder architecture
  train.py           Training loop, checkpointing, evaluation
models/          Saved model weights (final model committed, checkpoints ignored)
reports/figures/ Training curves and diagrams
tests/           Sanity tests for the data and model code
```

## Setup

Create and activate a virtual environment, then install dependencies.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

`tensorflow-metal` enables GPU acceleration on Apple Silicon. Confirm it is picked up with

```bash
python3 -c "import tensorflow as tf; print(tf.config.list_physical_devices())"
```

## Branching workflow

`main` is protected. Work happens on short-lived feature branches (`feature/<name>`),
merged back through a pull request. See `docs/development-plan.md` for the phased plan.
